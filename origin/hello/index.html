这一页是排版的示例，也是一份说明书。它放在 origin/hello/index.html， 构建之后就会变成 /hello/ 这个地址。喜欢的话可以留着，不喜欢直接删掉整个目录。

为什么是静态页面

静态站点没有数据库、没有运行时，也就没什么可坏的。所有页面在构建时生成好， 推到 GitHub 之后由 Actions 打包发布，剩下的事就是写内容。

写下来的东西才算真的想清楚了。 ——某人

一些常用排版

  • 列表项，用于罗列要点
  • 链接、加粗、斜体 都可以直接用 HTML
  • 代码块会用深色背景显示
npm run publish -- ./my-page.html my-page
npm run build

图片放在同目录下即可，构建时会被原样复制到输出目录，例如 <img src="./cover.png">。
